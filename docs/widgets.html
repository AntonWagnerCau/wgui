Widget reference

Every method available on Window, Grid and Horizontal. Widgets that accept user input take a &mut reference and return a Response; display widgets return nothing.

Availability matrix

The three containers overlap but are not identical. Horizontal in particular is limited to widgets that read well in a single row.

Sliders

slider Window Grid Horizontal Response 
fn slider(&mut self, label: &str, value: &mut f32, range: RangeInclusive<f32>) -> Response
fn slider_f64(&mut self, label: &str, value: &mut f64, range: RangeInclusive<f64>) -> Response
fn slider_int(&mut self, label: &str, value: &mut i32, range: RangeInclusive<i32>) -> Response
fn slider_uint(&mut self, label: &str, value: &mut u32, range: RangeInclusive<u32>) -> Response

A draggable track with a numeric readout. Floating point sliders use a step of (max - min) / 10000; integer sliders step by 1. The value is clamped to the range by the frontend. 

win.slider("Exposure", &mut exposure, 0.0..=8.0);
win.slider_int("Bounces", &mut bounces, 1..=32);
win.slider_uint("Sample Count", &mut samples, 1..=4096);

if win.slider_f64("Time Scale", &mut time_scale, 0.0..=4.0).changed() {
    resync_clock(time_scale);
}

Number inputs

number_input Window Grid Horizontal Response 
fn number_input(&mut self, label: &str, value: &mut f32) -> Response
fn number_input_f64(&mut self, label: &str, value: &mut f64) -> Response
fn number_input_int(&mut self, label: &str, value: &mut i32) -> Response
fn number_input_uint(&mut self, label: &str, value: &mut u32) -> Response

A free-typed numeric field with no track and no range clamp. Use it when the sensible range is unbounded or when exact values matter more than dragging. The _uint variant floors incoming negatives at zero. 

win.number_input("Emitter Radius", &mut radius);
win.number_input_int("Seed", &mut seed);

Checkbox

fn checkbox(&mut self, label: &str, value: &mut bool) -> Response

A labelled toggle.

if win.checkbox("Enable Denoiser", &mut denoise).changed() {
    rebuild_pipeline(denoise);

Text inputs

text_input Window Grid Horizontal Response 
fn text_input(&mut self, label: &str, value: &mut String) -> Response

A single-line field with a label column.

text_input_inline Horizontal Response 
fn text_input_inline(&mut self, placeholder: &str, value: &mut String) -> Response

The same field without the label column, for use inside a row. The first argument is the placeholder text shown while the field is empty, and it also determines the element id, so keep it stable.

kv_value Window Response 
fn kv_value(&mut self, label: &str, value: &mut String) -> Response

An editable key/value row: renders like kv but writes browser edits back into the string.

Dropdown

dropdown Window Grid Horizontal Response 
fn dropdown(&mut self, label: &str, selected: &mut usize, options: &[&str]) -> Response

A select box. selected is an index into options, written back when the user picks another entry. Changing the option list is allowed; keep the index meaningful when you do. 

const MODES: [&str; 4] = ["Albedo", "Normals", "Depth", "Beauty"];

if win.dropdown("Debug View", &mut mode, &MODES).changed() {
    set_debug_mode(mode);
}

Buttons

button Window Grid Horizontal Response 
fn button(&mut self, label: &str) -> Response

A full-width push button. clicked() is true for the single frame in which the press is consumed. On a Horizontal it renders as an inline button without a label column.

button_accent Horizontal Response 
fn button_accent(&mut self, label: &str, accent: AccentColor) -> Response

An inline button tinted with an explicit accent, for destructive or primary actions.

button_compact Window Grid Response 
fn button_compact(&mut self, label: &str) -> Response
fn button_compact_accent(&mut self, label: &str, accent: AccentColor) -> Response

A smaller button for dense panels, optionally accented.

if win.button("Reload Shaders").clicked() {
    reload_shaders();
}

win.horizontal(|h| {
    if h.button_accent("Start", AccentColor::Green).clicked() { start(); }
    if h.button_accent("Stop", AccentColor::Red).clicked() { stop(); }
    h.label("running");
});

Color pickers

color_picker Window Grid Horizontal Response 
fn color_picker(&mut self, label: &str, value: &mut [f32; 3]) -> Response
fn color_picker4(&mut self, label: &str, value: &mut [f32; 4]) -> Response

RGB and RGBA pickers over normalized 0.0..=1.0 components. The fourth component of color_picker4 is alpha. 

let mut tint = [1.0f32, 0.42, 0.13];
win.color_picker("Flame Tint", &mut tint);

let mut overlay = [0.0f32, 0.0, 0.0, 0.35];
win.color_picker4("Overlay", &mut overlay);

Labels and key/value

label Window Grid Horizontal 
fn label(&mut self, text: &str)

Free text. Unlike every other widget the text is the value, not the id, so a label's content can change every frame without churning element identity.

kv Window Grid Horizontal 
fn kv(&mut self, label: &str, value: &str)

A compact read-only key/value row. This is the right widget for live numbers: the key is stable and only the value updates. 

win.kv("Frame", &format!("{frame_ms:.2} ms"));
win.kv("Rays", &format!("{ray_count}"));
win.label("Press R to reload the scene.");

Stat cards

stat Window Grid 
fn stat(&mut self, label: &str, value: &str, subvalue: Option<&str>, accent: AccentColor)

A large accented number with a caption and an optional smaller secondary line. Built for grids: three or four across reads like a dashboard header. 

win.grid(3, |grid| {
    grid.stat("FPS", &fps.to_string(), Some(&format!("{frame_ms:.1} ms")), AccentColor::Green);
    grid.stat("Particles", &count.to_string(), Some("active"), AccentColor::Coral);
    grid.stat("VRAM", &format!("{vram_mb} MB"), None, AccentColor::Blue);
});

Status indicators

status Window Grid 
fn status(
    &mut self,
    label: &str,
    active: bool,
    active_text: Option<&str>,
    inactive_text: Option<&str>,
    active_color: AccentColor,
    inactive_color: AccentColor,
)

A colored dot with a caption that switches text and color on a boolean. Pass None for either text to fall back to the frontend's default wording. 

win.status(
    "GPU Capture",
    capturing,
    Some("Recording"),
    Some("Idle"),
    AccentColor::Red,
    AccentColor::Gray,
);

Progress bars

progress_bar Window Grid 
fn progress_bar(&mut self, label: &str, value: f64, accent: AccentColor)
fn progress_bar_with_subtitle(&mut self, label: &str, value: f64, accent: AccentColor, subtitle: &str)

A filled track. value is a fraction and is clamped to 0.0..=1.0, so pass ratios rather than percentages. The subtitle variant adds a line of context under the bar. 

win.progress_bar("Bake", baked as f64 / total as f64, AccentColor::Teal);

win.progress_bar_with_subtitle(
    "Convergence",
    samples as f64 / target as f64,
    AccentColor::Green,
    &format!("{samples} / {target} spp"),
);

Charts and plots

mini_chart Window Grid 
fn mini_chart(&mut self, label: &str, values: &[f32], unit: Option<&str>, accent: AccentColor)

A sparkline over the slice, with the last value shown as the current reading. The unit string is appended to that reading verbatim, so include any leading space you want.

plot Window Grid 
fn plot(
    &mut self,
    label: &str,
    series: &[(&str, &[f32], AccentColor)],
    x_label: Option<&str>,
    y_label: Option<&str>,
)

fn plot_with_autoscale(
    &mut self,
    label: &str,
    series: &[(&str, &[f32], AccentColor, bool)],
    x_label: Option<&str>,
    y_label: Option<&str>,
)

A larger multi-series chart with a legend and optional axis captions. Each tuple is (name, values, color), plus an autoscale flag in the plot_with_autoscale form: true normalizes that series independently, false puts it on the plot's shared scale. Plain plot autoscales every series. 

win.mini_chart("Frame Time", &frame_ms, Some(" ms"), AccentColor::Coral);

win.plot(
    "Performance History",
    &[
        ("FPS", &fps_history, AccentColor::Green),
        ("Memory", &memory_history, AccentColor::Blue),
    ],
    Some("Time"),
    Some("Value"),
);

Images

image Window Grid Horizontal 
fn image(&mut self, label: &str, data_uri: &str)
fn image_with_size(&mut self, label: &str, data_uri: &str, width: u32, height: u32)  // Window only

Displays a base64 data URI such as "data:image/png;base64,…". The size variant supplies an explicit size hint so the layout does not jump while the image decodes.

image_button Window Grid Response 
fn image_button(&mut self, label: &str, data_uri: &str, selected: bool) -> Response

A clickable thumbnail that reports presses like a button. selected draws a highlight border, which makes a grid of these a workable picker. 

win.grid(4, |grid| {
    for (i, thumb) in thumbnails.iter().enumerate() {
        if grid.image_button(&thumb.name, &thumb.uri, i == active).clicked() {
            active = i;
        }
    }
});

Grid and horizontal

grid Window Grid 
fn grid<F>(&mut self, cols: usize, f: F)
where
    F: FnOnce(&mut Grid<'_, '_>)

Lays its children out in cols equal columns, filling row by row in declaration order. Grids nest to arbitrary depth.

horizontal Window 
fn horizontal<F>(&mut self, f: F)
where
    F: FnOnce(&mut Horizontal<'_, '_>)

Packs its children into one row that the frontend never splits across layout columns. Rows do not nest and cannot contain grids. 

win.grid(2, |grid| {
    grid.stat("Solid", &solid.to_string(), None, AccentColor::Blue);
    grid.stat("Fluid", &fluid.to_string(), None, AccentColor::Teal);

    grid.grid(2, |inner| {
        inner.checkbox("Wireframe", &mut wireframe);
        inner.checkbox("Bounds", &mut bounds);
    });
});

win.horizontal(|h| {
    h.label("Scene");
    h.text_input_inline("path…", &mut scene_path);
    if h.button("Load").clicked() {
        load_scene(&scene_path);
    }
});

A group header inside a window.

A horizontal divider.

set_accent Window 
fn set_accent(&mut self, accent: AccentColor)

Sets the accent color of the window it is called on. Call it once, near the top of the window. Widgets that take an explicit accent argument still win for themselves.

Types

Response

pub struct Response { /* … */ }

impl Response {
    pub fn clicked(&self) -> bool;
    pub fn changed(&self) -> bool;
}

clicked() reports that an edit for this element arrived from the browser and was consumed this frame. changed() additionally requires the value to differ from what it was. Both are false on frames with no interaction, and the result is not sticky: read it in the frame it is returned.

pub enum AccentColor {

impl AccentColor {

AccentColor is Copy, so it can be stored in configuration structs and passed around freely. Conventionally: green for healthy, red for stopped or destructive, orange or yellow for warnings, and the rest for grouping.
